> ⚠️ Archived. This is an old version of my personal website, kept for reference. It is no longer deployed or maintained.

A static personal site in plain HTML, CSS and JavaScript, originally hosted on GitHub Pages.

### ✨ What's in it
- 🏠 `index.html`: landing page
- 👤 `about.html`, `work.html`: about me and work experience
- ✉️ `contact.html`: contact form (Formspree; the form ID is a `YOUR_FORM_ID` placeholder)
- 🎆 Particle background on the inner pages ([particles.js](https://github.com/VincentGarreau/particles.js)), Font Awesome icons
- 🔗 `projects.html` just redirects to my GitHub profile

### 🚀 View locally
```bash
git clone https://github.com/canmenzo/old-canmenzo.com
cd old-canmenzo.com
python3 -m http.server 8000   # then open http://localhost:8000
```
